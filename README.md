# Simple miXML Converter to CSV, FASTA

**You can get your input data from:** [EBI IntAct Interactomes](https://www.ebi.ac.uk/intact/interactomes)  
**Note:** If you encounter input errors, try placing your input files directly into the cloned directory.

---

## CSV_generator.py

**Description:**  
Generates CSV files from miXML files with the `mif300` (miXML 3.0) schema.

**Usage:**
```bash
CSV_generator.py -in <inp_1.xml> ... <inp_n.xml>
```

**Output:**
- `<inp_1.csv>` ... `<inp_n.csv>`

---

## MIscore.py

**Description:**  
Uses the IntAct API. This script takes the Interaction AC column from the CSV files generated by `CSV_generator.py`. It queries the IntAct database in JSON format and extracts the MIscore field.

**Usage:**
```bash
MIscore.py -in <inp_1.csv> ... <inp_n.csv>
```

**Output:**
- `<inp_1_MI_scores.csv>` ... `<inp_n_MI_scores.csv>`

---

## add_MI_score.py

**Description:**  
Merges the output files of `MIscore.py` and `CSV_generator.py`.  
**Input files should be the outputs of `CSV_generator.py`.**

**Usage:**
```bash
add_MI_score.py -in <inp_1.csv> ... <inp_n.csv>
```

**Output:**
- `<inp_1_w_MI_score.csv>` ... `<inp_n_w_MI_score.csv>`

---

## FASTA_generator.py

**Description:**  
Generates FASTA files from miXML files with the `mif300` schema.

**Usage:**
```bash
FASTA_generator.py -in <inp_1.xml> ... <inp_n.xml>
```

**Output:**
- `<inp_1.fasta>` ... `<inp_n.fasta>`
